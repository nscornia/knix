## Rule

- Text a user reads comes from the translation catalog through the project's translate call, in markup and in code alike: content, labels, column headers, messages, and attribute text such as `placeholder`, `title`, `alt` and `aria-label`. A literal is fine only for what nobody reads as language: keys, identifiers, class names, test hooks and placeholder symbols such as `--`. A message with variable parts is one catalog entry with placeholders, never fragments joined in code.
