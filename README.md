# knix

Organization-neutral TypeScript utilities, code-quality lint tooling and shareable AI-agent config, published under three npm scopes.

| Package | Purpose |
|---|---|
| `@knix/utils` | Framework-agnostic TypeScript utilities, one tree-shakable entry point per area. |
| `@knix-law/eslint-plugin` | ESLint rules for the [knix laws](knowledge/law/README.md). |
| `@knix-law/eslint-config` | Shareable ESLint config composing those rules. |
| `@knix-law/stylelint-plugin` | Stylelint rules for the knix laws. |
| `@knix-law/stylelint-config` | Shareable Stylelint config composing those rules. |
| `@knix-ai/config` | An ecorn AI-config baseline layered on `@ecorn/config`. |

No package is published yet.

## Boundary

Other projects may depend on published knix packages; knix never depends on or names them. The repository holds no organization-specific content, and all code is written fresh for it.
